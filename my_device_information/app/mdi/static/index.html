Create a snapshot

Collects your Home Assistant setup into files you can paste into any AI chat. Nothing is uploaded anywhere. Pick which files to create and how much to mask in each one.

Standard masks passwords, tokens, emails, MACs and coordinates. Strict also masks IPs, hostnames, serials and person names. None shares everything (private setups only).

Automatic updates

Re-creates the files in the background using the selection above. Changes apply right away, no restart needed.

MQTT sensor

Publishes the whole Full file as a sensor in Home Assistant, so templates and dashboards can read it. The sensor's state is the time of the last snapshot and the text is in its attribute. Needs the MQTT integration. It is updated every time a snapshot is created.
